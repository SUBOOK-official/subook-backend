# 전일학원 정산

2026-09-30 사용자 요청: 전일학원 모의고사는 어드민 정산에서 일반 셀러와 별도로 표시한다. 수수료는 50%이며, 사용자가 기존 입금 내역은 없다고 확인했다.

- 전일학원 자체판매 교재의 구매확정·결제 완료 품목만 지급 대상으로 집계한다. 주문 품목의 당시 교재금액(쿠폰·포인트 차감 전)을 사용하고 배송비와 수거 비용은 포함하지 않는다.
- 미확정 판매분과 환불 처리 중인 주문은 대기 내역으로 표시한다. 취소·환불 완료분과 기존 셀러 정산 원장에 포함된 교재는 제외한다.
- 원장님께 직접 계좌이체한 뒤, 어드민에서 대상 품목·합계·이체 메모를 확인해 지급 완료를 기록한다. RPC는 계좌이체나 알림 발송을 실행하지 않는다.
- 주문과 주문 품목 잠금을 획득한 후 대상을 재검증한다. 대상 수/금액이 달라지면 전체 요청을 거부하며 품목당 한 번만 지급 원장에 기록할 수 있다.
- 지급 후 환불이 발생해도 지급 당시 금액과 기록은 보존하며, 조회 응답에 확인 표시를 남긴다. 미지급으로 다시 포함하지 않는다.
- 원장은 관리자만 조회할 수 있다. 직접 수정 권한은 없으며 관리자 검증을 거치는 지급 RPC로만 기록한다.

검증: `node scripts/test-jeonil-settlement.mjs`는 격리된 PGlite DB에서 실제 migration을 실행해 금액/수량, 대상 제외, 변경된 금액 거부, 중복 방지, 지급 후 환불, 관리자 권한과 RLS를 확인한다. 운영 데이터에 테스트 지급 기록을 만들지 않는다.

되돌리기: 프런트엔드 연결을 해제한다. 실제 지급 기록이 있다면 원장 테이블과 조회 기능을 보존한다.
